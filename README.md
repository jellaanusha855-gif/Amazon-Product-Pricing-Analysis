# Amazon Product Pricing Analysis

## 📌 Project Overview

Amazon Product Pricing Analysis is a data analysis project that explores Amazon product pricing data to understand product prices, ratings, discounts, and customer purchasing trends. The project focuses on analyzing product-related information to identify useful patterns and insights from the dataset.

## 🎯 Objectives

- Analyze product pricing and discount patterns.
- Explore product ratings and customer preferences.
- Identify trends in product prices.
- Perform Exploratory Data Analysis (EDA).
- Generate meaningful insights using data visualization.

## 🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 🔍 Key Activities

- Data loading and inspection
- Data cleaning and handling missing values
- Exploratory Data Analysis (EDA)
- Product price and rating analysis
- Data visualization and insights
