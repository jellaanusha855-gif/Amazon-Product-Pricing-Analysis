# 🛒 Amazon Product Pricing Analysis

## 📌 Project Overview

Amazon Product Pricing Analysis is an end-to-end data analytics project using Python and Power BI to analyze Amazon product prices, discounts, ratings, bestseller status, and coupon availability.

The project focuses on exploring product-related data to identify pricing patterns, understand product performance, and generate meaningful insights through data analysis and dashboard visualization.

## 🎯 Problem Statement

Understanding product pricing, discounts, customer ratings, and promotional offers can help reveal patterns in product performance across an e-commerce marketplace.

The objective of this project is to analyze Amazon product data to understand:

- Product pricing patterns
- Discount distribution
- Product ratings and customer preferences
- Bestseller status and pricing differences
- Coupon availability
- Relationships between product prices and other available attributes

## 🎯 Project Objectives

1. Load, clean, and validate the Amazon product dataset.
2. Handle missing values and prepare the data for analysis.
3. Perform Exploratory Data Analysis (EDA).
4. Analyze product prices and discount patterns.
5. Explore product ratings and bestseller status.
6. Analyze coupon availability across products.
7. Build an interactive dashboard to visualize key metrics.
8. Generate meaningful insights from the analysis.

## 📊 Power BI Dashboard

### Amazon Product Performance Analysis

The dashboard provides an overview of Amazon product pricing and performance using key metrics and interactive visualizations.

### Key Dashboard Metrics

| Metric | Value |

### Dashboard Visualizations

- **Average Listed Price by Rating:** Explores listed prices across product rating values.
- **Distribution by Price:** Shows the distribution of product prices.
- **Average Price by Bestseller Status:** Compares average current or discounted prices across bestseller categories.
- **Coupon Availability:** Compares the number of products with and without coupon availability.
- **Listed Price Range:** Allows the displayed price range to be filtered.
